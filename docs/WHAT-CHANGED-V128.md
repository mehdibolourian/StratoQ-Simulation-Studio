# StratoQ Studio v1.2.8 — Compact playback and demand-path visualization

Based on v1.2.7, with no changes to the optimizer, scientific channel physics, trajectory interpolation or PPO policy.

1. **Timeline:** collapsed by default to play/pause, current time, scrubber and progress. Chevron expands time-slot settings and three or four short story cues. The existing top **Experiment story** button opens the detailed dialog. No default stacked commentary.
2. **Reset Scenario:** restores this tab's baseline configuration, including all original HAPs, GSs, demands, weather, horizon, trajectory and algorithm. It cancels an in-flight UI result and invalidates old frames; click Run Simulation to recompute. Saved tabs from before v1.2.8 without a baseline use the appropriate builtin preset or, for a custom tab, its current saved configuration. New Experiment is still the only source of the 2-GS/1-HAP template.
3. **Popup layering:** all React Three Drei `Html` labels use `zIndexRange={[30,0]}`, below the fixed story dialog. No global macOS/browser security settings change.
4. **Simpler stories:** five showcase scripts reduced to algorithm-specific questions with 3–4 short cues. Cues are guideposts, not measured facts. If no corresponding event is observed, that is reported.
5. **Demand identity:** each configured demand has a stable hue in the 3D scene, map, workspace list, link inspector and scene legend. Brightness scales with the demand's *current served rate relative to the largest requested rate in that slot*; it is not physical-link capacity. When several demands share a GS–HAP link, they appear in separate parallel lanes, not blended into one misleading color. No GS-GS shortcut line is created. Link state uses actual per-link `fresh_used_bps` and `qkp_used_bps` from the existing Gurobi solve; *solid* represents fresh, *dashed* QKP and *solid + dashed* mixed link usage. The fresh/QKP split is per **link**, not provably per demand—this matters when flows share a link. Older frame files fall back to their existing activation/allocations flags.
6. **Optional actual historical day:** the story dialog has `Try historical ERA5 · 2024-06-21`. It creates a **separate experiment** with the previously bundled Open-Meteo ERA5 data for 2024-06-21 UTC and removes scripted weather. This is *reanalysis*, not a forecast. Its observed weather may not create a dramatic QKP gap, and saved-scripted story cues are not attached to that copy. The controlled QKP-on/off demo retains its intentionally scheduled storm to isolate storage's causal impact. The bundled historic day includes a late-UTC-day rain period in some grid cells; exact site impacts are computed, not assumed.

## Installation

Stop the existing servers, then unzip the incremental patch at the project root and use the existing `./start-stratoq.sh`. No new Python dependencies are introduced. A browser hard refresh may be necessary to reload Vite assets. Workspaces saved before this version remain readable. As usual, run science-grade end-to-end checks on the Mac with Gurobi and compiled LOWTRAN before presenting numeric claims.
